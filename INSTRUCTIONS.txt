PAC-MAN — Linux standalone

Extract the ENTIRE pac-man directory, preserving _internal and its files.
From a writable terminal directory containing the extracted files, run:
    ./pac-man config.json
Exactly one JSON configuration path is required. No Python install is needed.
Linux with a graphical X11 session and system X11/OpenGL libraries is required.
Do not run the executable alone without its _internal directory.

CONTROLS
Menu: arrow keys to select, Enter to confirm; mouse buttons are also supported.
Movement: arrow keys or WASD.
Pause: Esc or P; Enter resumes. Pause menu can return to the main menu.
Close the window or choose Exit in the main menu to quit.
Eat dots to complete levels, avoid ghosts, and use power pellets to eat ghosts.
After victory or defeat, enter a name (10 alphanumeric/space characters max)
and confirm with Enter to save the score.

EVALUATION OPTIONS
C toggles cheat controls. With cheats enabled: I toggles invincibility,
N skips a level, F freezes ghosts, L adds a life, B toggles increased speed,
V activates power. Main menu also provides instructions and top ten highscores.

CONFIGURATION
Edit config.json or pass another .json file. Lines beginning with # are ignored.
Set levels (array of level_number/width/height), pacgum, seed, level_max_time,
lives, window_width, window_height,
points_per_pacgum, points_per_super_pacgum, points_per_ghost, and
highscore_filename. Invalid values use safe defaults with diagnostic messages.
Keep the configured highscore location writable to persist scores.
See README.md when included for all supported keys and defaults.
