# Project Management

This directory contains the project-management records required by the Pac-Man
subject. It documents planning and progress, technical decisions, risks, team
responsibilities, important bugs and fixes, and the final acceptance procedure.

## Contents

- [`PLAN_AND_PROGRESS.md`](PLAN_AND_PROGRESS.md) — milestones, planned outcomes,
  actual progress, and remaining release work.
- [`TEAM_ORGANIZATION.md`](TEAM_ORGANIZATION.md) — contributors, responsibilities,
  and working approach.
- [`DESIGN_DECISIONS.md`](DESIGN_DECISIONS.md) — architectural and gameplay
  decisions.
- [`RISKS.md`](RISKS.md) — identified project risks and mitigations.
- [`BUGS_AND_FIXES.md`](BUGS_AND_FIXES.md) — representative defects and their
  resolutions.
- [`ACCEPTANCE_TEST_PLAN.md`](ACCEPTANCE_TEST_PLAN.md) — final lint, manual,
  packaging, and release checks.

Automated regression tests were used during development but are not included in
the final submission repository. The submitted project therefore uses the source
code, Git history, configuration, lint/type-checking results, project-management
records, and final manual acceptance checks as its current verification evidence.
