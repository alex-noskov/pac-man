# Project Management

This directory contains the project-management evidence required by the Pac-Man subject. It documents planning, progress, technical decisions, risks, team responsibilities, testing, and notable bugs fixed during development.

## Contents

- [`PLAN_AND_PROGRESS.md`](PLAN_AND_PROGRESS.md) — milestones, planned outcomes, and current status.
- [`TEAM_ORGANIZATION.md`](TEAM_ORGANIZATION.md) — contributors and areas of responsibility.
- [`DESIGN_DECISIONS.md`](DESIGN_DECISIONS.md) — important architectural and gameplay choices.
- [`RISKS.md`](RISKS.md) — project risks and mitigations.
- [`BUGS_AND_FIXES.md`](BUGS_AND_FIXES.md) — representative defects and the corresponding fixes/regressions.
- [`ACCEPTANCE_TEST_PLAN.md`](ACCEPTANCE_TEST_PLAN.md) — acceptance criteria and verification procedure.
- [`evidence/README.md`](evidence/README.md) — verification evidence and final release checklist.

The repository source code, automated tests, Git history, configuration, and packaging scripts remain the primary technical evidence. This folder summarizes that evidence without duplicating the implementation documentation in the root `README.md`.
